## Root causes (already investigated — do not re-investigate)
- `growl_bass` ignores MIDI pitch: `GrowlBassEngine.cpp:410` uses the fixed `fundamentalHz` whenever it's >10 Hz. The demo pins it at 55 Hz → bass sits in the kick's sub range regardless of the notes the generator writes.
- `psy_fm` growlBass preset is polyphonic/MIDI-following (operator-ratio FM, carrier at note pitch) → the right engine for a bass that tracks the generator's offbeat F2+ notes.
- The arp wash = psyarp built-in delay (wet 0.45 / fb 0.6 / ping-pong) + "Arp Width" chain delay + an LFO modulating delay feedback toward ~0.95.
- Leads get ~1 filter LFO each; chorus/flanger/phaser/synced-delay/modulation are available and verified working (chorus no-op was a probe artifact, fixed this session).

## Steps

### 1. Helper
Add to `demo_compose.py`:
```python
def fx_slot_index(e, tid, fxtype):
    r = e.tool("list_fx", {"trackId": tid})
    if not isinstance(r, list):
        return -1
    for s in r:
        if s.get("type") == fxtype:
            return int(s.get("slot", -1))
    return -1
```

### 2. Bass → psy_fm growlBass (frequency trade-off + MIDI-follow)
- `fx` dict: `"bass": "psy_fm"` (was `growl_bass`).

### 3. Tame the arp
