## Workstreams

### O1 — `growl_bass` pitch contract — **DONE 2026-10-03** (minimal additive code fix)
- **Design (chosen): expose the existing dead branch.** The engine already implements MIDI-follow
  (`GrowlBassEngine.cpp:410` `baseFreq = (fundHz > 10.0f) ? fundHz : midiFreq`); it is unreachable
  only because the exposed minimum is 20 Hz. Change the def-table min `20.0f → 0.0f` (default stays
  **55.0f**), change the engine threshold `> 10.0f → > 0.0f`, and define **exactly `0` = follow the
  MIDI note**. All existing projects (55, or any value ≥ 20) render bit-identically — the only newly
  reachable value is 0. No new parameter, no route/parity/device-map-shape change.
- **Rejected alternative:** a separate `Note Map`/`Pitch Mode` param — needs contract + device-map +
  parity work with no demonstrated need.
- **Risk:** low. Touches one def-table range and one comparison; the DSP branch already exists.
- **Sign-off:** authorised by the user ("lets fix these issues starting with 01").
- **Success gates:** (1) `TrackFXSlot::getParamDefsForType("growl_bass")[0]` min `0.0f` / default `55.0f`;
  (2) a default-params render is bit-identical for note 36 vs note 48; (3) with `Fundamental Hz = 0`
  the two notes render differently (pitch follows); (4) `set_internal_fx_param {value:0}` lands
  un-clamped and round-trips through the tree; (5) `dsh-build-fast.bat test` green + affected suites
  pass; (6) regenerated `device_map/growl_bass.params.json` min `0.0` with `--check` clean; (7) guide
  docs updated.
