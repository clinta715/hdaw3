### 2.1 The drain seam (new capability — use it, don't sleep)

- **API:** `AudioEngine::drainPendingRoutingRebuild()` (public,
  `src/engine/AudioEngine.cpp` ~1295). Marshals
  `AsyncUpdater::handleUpdateNowIfNeeded()` onto the message thread via
  `callFunctionOnMessageThread` (same pattern as the engine-internal
  `runOnMessageThread` helper, MainAudioProcessor.cpp:36-70).
- **Why a public method (not test-side):** `AudioEngine` PRIVATELY inherits
  `juce::AsyncUpdater` (AudioEngine.h:26) — compiler-verified C2247/C2248 in
  a first attempt that was cleanly reverted. One minimal self-marshaling
  method is the designed seam; it honors the "do NOT add engine APIs
  casually" constraint from the previous handoff.
- **Semantics (verified against JUCE source):** exactly-once delivery vs
  the pump's own dispatch (`shouldDeliver` atomic exchange); no-op when
  nothing pending; blocks until the rebuild COMPLETES. On the message thread
  `rebuildRoutingGraph` takes its no-park path (no lesson-12 deadlock, no
  lesson-18 instantiation trap — that trap only bites off-message-thread
  parks).
- **Bonus property — general pump barrier:** the message queue is FIFO, so
  anything queued BEFORE the drain call (including the
  `AudioProcessorGraph` render-sequence bake triggered by
  `graph.prepareToPlay`, which escalates to an inline `handleAsyncUpdate`
  on the message thread — juce_AudioProcessorGraph.cpp:1862) lands before
  it returns. This is what makes a drain placed AFTER explicit
  `rebuildRoutingGraph()` calls deterministic.
- **Rule (now in docs/testing-mcp.md):** engine tests that need a settled
  routing graph before touching live processors MUST call
  `engine.drainPendingRoutingRebuild()` — never a fixed
  `juce::Thread::sleep()`. Caller contract: any thread except the message
  thread, and must not hold a `MessageManagerLock`.
- Evidence: all 4 sleeps in `audio_pool_dedup_test.cpp` replaced (both race
  windows in `ClipAndSamplerShareOneDecodeAcrossRebuild` now closed);
  10/10 determinism runs; 18/18 rebuild-adjacent suites re-verified
  independently; 816/816 full suite.
