## 6. New traps this session (beyond lessons 1–34)

1. `dsh-build-fast.bat` with no argument builds ONLY the `HDAW` target —
   `HDAW_headless.exe` stays stale (the lesson-15/34 instance: B6's
   `ceilingHitPct` read "absent" until `dsh-build-fast.bat all`).
2. Windowed renders do not predict full-render sums (§3).
3. The detached-task registry is ephemeral across compactions/session
   restarts — manage engine processes by PID.
4. A concurrent-build race corrupts the build dir: `C1083 Permission denied`
   on compiler-generated `.obj` + wandering SIGSEGV in heavy suites (death
   point moves between runs; dying tests pass solo; no crash artifacts).
   Recovery: delete `build/CMakeFiles`, `.ninja_deps`, `.ninja_log`,
   reconfigure, full rebuild.
5. `.hdaw` is ValueTree **XML**; notes are `<MIDI_NOTE noteID=… startBeat=…>`
   elements (clip-local beats) — never `<NOTE>`; tags span lines.
6. Engine MCP: `--mcp-stdio` is the transport the launcher uses; the
   crash-capture wrapper (`mcp-launch-capture.ps1`) fails under the sandbox —
   launch `build/HDAW_headless.exe` directly for agent workflows.
7. Windows console cp1252 chokes printing engine JSON (U+FFFD) —
   `PYTHONIOENCODING=utf-8` for any parser/printer.
